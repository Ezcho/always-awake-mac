no-sleep-pika

화면은 쉬어도, 작업은 계속.

앱 실행이 차단된 경우

먼저 Applications의 pika를 열어 보세요. macOS가 개발자를 확인할 수 없다고 차단한 경우에만 시스템 설정 → 개인정보 보호 및 보안에서 pika인지 확인한 뒤 그래도 열기를 직접 선택합니다. Apple 공식 안내

앱이 이미 열리지만 보조 서비스 연결에 실패하는 문제는 별도입니다. 보안 설정의 앱 열기 허용만으로 보조 서비스 연결을 보장하지 않습니다.

바로 시작

  1. pika.app을 응용 프로그램 폴더로 옮겨 실행합니다.
  2. 덮개를 열어 둔 채 Session ON을 누릅니다.
  3. 덮개 모드는 대기 중 상태에서 Monitor를 선택하고 덮개를 닫으면 동작합니다. ON만 눌러서는 화면이 꺼지지 않습니다.

덮개 모드 설치

앱은 DMG에서 Applications로 드래그해 설치합니다. 앱의 설치 안내창에서 보조 서비스 설치를 선택하면 현재 앱과 일치하는 보조 서비스만 다운로드하고 검사합니다. pika가 종료되고 macOS 설치 프로그램이 열리면 직접 관리자 승인을 완료한 뒤 pika를 다시 실행합니다. 이전 앱 관리형 보조 서비스 등록도 설치 준비 과정에서 정리합니다. Session과 잠자기 설정이 안전하게 복구되지 않으면 설치를 진행하지 않습니다.

두 개의 스위치

Monitor는 Session ON일 때만 조작할 수 있습니다. Session OFF에서는 Monitor도 OFF로 표시되고 비활성화되며, 화면은 즉시 꺼지지 않습니다. 다음 Session에서는 마지막 Monitor 선택을 복원합니다.

덮개 모드는 대기 중 Monitor 선택을 저장했다가 덮개가 닫히면 적용합니다. 다시 열면 화면 제어를 해제하고 대기로 돌아갑니다. Monitor ON은 화면의 자동 잠자기를 막습니다. OFF는 적용 시점부터 3초 뒤 화면 잠자기를 요청합니다. 키보드나 마우스로 다시 켤 수 있으며 화면 잠금과는 다릅니다.

메뉴 막대 아이콘 클릭으로 스위치를 열고, Option+클릭으로 세션을 전환합니다. 제어창의 X는 창만 닫습니다. 메뉴의 제어창 열기로 다시 표시하고 종료로 앱을 끝냅니다.

배터리·열 상태

보조 서비스는 5초마다 전원·배터리·덮개·외장 화면·macOS 열 상태를 확인합니다. 덮개가 닫히고 외장 화면이 없는 경우 배터리 기준을 25%로 강화합니다. 안전 기준에 도달하면 잠자기 방지를 해제하고 Mac 잠자기를 요청합니다. 중단한 세션은 자동 재시작하지 않습니다.

MCP 연결

앱을 실행한 뒤 MCP 클라이언트에서 STDIO 서버를 추가하세요. 실행 명령: /Applications/pika.app/Contents/MacOS/pika-mcp

pika_status로 상태를 확인하고, pika_set_session과 pika_set_monitor에 enabled: true/false를 전달합니다. MCP를 종료해도 앱 세션은 유지됩니다.

설치와 삭제

macOS 13 이상, Apple Silicon 및 Intel을 지원합니다. 이 다운로드는 Developer ID 서명·Apple 공증이 없어 macOS에서 앱 실행 확인이 필요할 수 있습니다. 보조 서비스의 서명 제한과 메인 앱의 실행 확인은 별개입니다.

Session OFF 후 앱을 종료하고 휴지통으로 옮기세요. 이전 보조 서비스가 설치되어 있다면 앱 관리형 서비스는 설정 → 보조 서비스 제거를 선택합니다. 설치 패키지로 추가한 서비스는 별도의 helper 제거 패키지로 삭제합니다. AI 서비스 제한, 네트워크 끊김, 프로그램 자체 종료는 관리하지 않습니다.
