Always Awake

화면은 쉬어도, 작업은 계속.

처음 한 번 준비

  1. 앱을 응용 프로그램 폴더로 옮겨 실행합니다.
  2. 덮개 모드 준비를 누르고, macOS 시스템 설정 → 로그인 항목 및 확장 프로그램에서 Always Awake를 허용합니다.
  3. 앱으로 돌아와 Session ON을 누릅니다.

두 개의 스위치

Session ON은 Mac이 덮개 닫힘·유휴 상태 때문에 잠드는 것을 막습니다. OFF는 원래 잠자기 동작을 복구합니다. 전원 꺼짐, 재시동, 네트워크 끊김이나 앱 자체 오류까지 막지는 않습니다.

Monitor ON은 세션 중 화면을 켜 두고, OFF는 3초 후 화면만 잠자기로 보냅니다. 키보드나 마우스로 화면을 다시 켤 수 있습니다. 화면 잠금과는 다릅니다. 덮개를 닫으면 내장 화면은 꺼집니다.

메뉴 막대 아이콘 클릭은 세션 ON/OFF, 우클릭 또는 Option+클릭은 제어창을 엽니다. 창을 닫아도 세션은 계속됩니다.

상태별 자동 보호

상태잠자기 기준
덮개 닫힘 + 외장 화면 없음배터리 ≤ 25% 또는 열 상태 높음
일반 사용배터리 ≤ 15% 또는 열 상태 위험
Desktop: 전원 + 외장 화면열 상태 위험

배터리 기준은 충전기 없이 사용할 때 적용됩니다. 온도는 macOS의 열 상태(정상·주의·높음·위험)를 사용하며 섭씨 측정값은 아닙니다. 보조 서비스가 5초마다 점검합니다. 기준에 도달하면 세션을 해제하고 Mac을 잠자기로 보냅니다. 개별 작업을 저장하거나 종료하는 기능은 없으며, 안전 중단 후 세션은 직접 다시 켜야 합니다.

Mac을 통풍이 되는 곳에 두세요. 가방 안이나 밀폐된 장소에서의 안전을 보장하지 않습니다.

종료·삭제·복구

하단 ··· 메뉴에서 앱을 종료할 수 있습니다. 제거하려면 먼저 보조 서비스 제거를 누르고 앱을 종료한 뒤 휴지통으로 옮기세요. 세션 중 앱이 중단되면 보조 서비스가 연결 종료 또는 마지막 응답으로부터 약 40초 이내에 잠자기 설정을 복구합니다. 보조 서비스 자체가 종료된 경우 macOS가 재시작할 때 기록을 읽어 복구합니다.

보조 서비스까지 강제로 제거되면 자동 복구가 불가능할 수 있습니다. 앱을 다시 설치하거나 터미널에서 sudo /usr/bin/pmset -a disablesleep 0으로 복구할 수 있습니다.

MVP 배포 안내

이 버전은 Apple Developer ID 서명·공증 전 테스트 빌드입니다. macOS 13 이상에서 실행되며 Apple Silicon과 Intel 실행 파일을 포함합니다. 덮개 닫힘 동작은 macOS의 비공개 전원 설정에 의존하므로 OS·기기별 실제 검증이 필요합니다. 브라우저 탭이나 AI 서비스 자체의 중단 정책은 변경하지 않습니다.

출처를 확인한 앱의 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 사용할 수 있습니다. macOS 전체 보안 기능을 끄지 마세요.
