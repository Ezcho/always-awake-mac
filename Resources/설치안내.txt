pika 1.0.4 — macOS 13 이상 / Apple Silicon + Intel

1. pika.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 pika를 실행합니다.
3. 덮개를 열어 둔 채 Session을 ON으로 켭니다.
4. 화면만 끄려면 Monitor를 OFF로 바꿉니다. 3초 뒤 화면 잠자기를 요청합니다.

웹 다운로드는 일반 모드로 동작합니다. 관리자 보조 서비스 없이 Mac의 유휴 잠자기를
방지합니다. 덮개를 닫거나 Mac을 직접 잠자기로 전환하면 세션이 끝납니다.
덮개를 닫은 채 실행하려면 pika-1.0.4.pkg를 설치하세요. macOS 설치창에서 관리자 승인이 필요합니다.
설치 전 Session OFF 후 앱을 종료하세요. 이전 보조 서비스가 있다면 먼저 제거하세요.
패키지는 앱과 보조 서비스를 함께 업데이트합니다. 설치 후 앱에서 덮개 모드가 확인되어야 합니다.
설치형 보조 서비스는 pika-helper-uninstall-1.0.4.pkg로 제거합니다.
현재 다운로드는 Developer ID 서명·Apple 공증이 없어 macOS에서 앱 실행 확인이 필요할 수 있습니다.

메뉴 막대 아이콘 클릭 = Session / Monitor 스위치
Option + 메뉴 막대 아이콘 클릭 = Session 즉시 ON/OFF
실행하면 작은 제어창이 표시됩니다. X로 닫아도 메뉴 막대에서 계속 실행됩니다.
Session OFF일 때 Monitor도 OFF로 표시되고 비활성화됩니다. 실제 화면은 즉시 꺼지지 않습니다.
앱 종료는 메뉴의 ‘종료’를 누릅니다.

일반 모드 보호:
- 외부 전원 없이 배터리 15% 이하 또는 macOS 열 상태 ‘위험’이면 세션 종료
- 덮개가 닫히거나 Mac이 잠자기에 들어가면 세션 종료
- 안전 중단 후 자동 재시작하지 않음
세션 종료는 pika의 잠자기 방지를 해제합니다. 다른 앱의 잠자기 방지까지 강제로 끄거나
개별 작업을 일시정지하지 않습니다. 가방 안 사용의 안전을 보장하지 않습니다.

MCP: STDIO 서버 명령을 아래 경로로 등록합니다. 별도 Python/Node 설치는 필요 없습니다.
/Applications/pika.app/Contents/MacOS/pika-mcp
도구: pika_status / pika_set_session / pika_set_monitor
MCP 클라이언트를 닫아도 GUI 앱의 세션은 유지됩니다. OFF 도구나 앱 스위치로 종료하세요.

Monitor OFF는 화면 잠자기이며 화면 잠금은 아닙니다. 키보드/마우스로 다시 켤 수 있습니다.
앱은 AI Agent를 대신 실행하거나 재시작하지 않습니다.
삭제: Session OFF → 앱 종료 → 앱을 휴지통으로 이동.
이전에 보조 서비스를 설치했다면 메뉴의 설정 → 보조 서비스 제거를 먼저 사용하세요.
