Always Awake 1.0.1 — macOS 13 이상 / Apple Silicon + Intel

1. Always Awake.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 Always Awake를 실행합니다.
3. 상단 메뉴 막대 아이콘 → ‘권한 허용…’를 누릅니다.
4. macOS 시스템 설정의 로그인 항목 및 확장 프로그램에서 Always Awake를 허용합니다.
5. Session을 ON으로 켜고, 화면을 끄려면 Monitor를 OFF로 바꿉니다.

메뉴 막대 아이콘 클릭 = Session / Monitor 스위치
Option + 메뉴 막대 아이콘 클릭 = Session 즉시 ON/OFF
별도 창은 없습니다. 앱 종료는 메뉴의 ‘종료’를 누릅니다.

현재 MVP는 Apple Developer ID 서명·공증 전의 테스트 빌드입니다.
웹에서 받은 앱이 차단되면 출처를 확인한 뒤 시스템 설정 > 개인정보 보호 및 보안에서
‘확인 없이 열기’를 이용할 수 있습니다. 시스템 전체 Gatekeeper를 끌 필요는 없습니다.

과열·방전 보호:
- 외장 화면 없이 덮개 닫힘: 배터리 25% 이하 / 열 상태 ‘높음’부터 잠자기
- 일반: 배터리 15% 이하 / 열 상태 ‘위험’에서 잠자기
- Desktop (전원 + 외장 화면): 열 상태 ‘위험’에서 잠자기
- 안전 중단 후 세션은 자동 재시작하지 않습니다.

통풍이 되는 곳에서 사용하세요. 가방 안 사용의 안전을 보장하지 않습니다.
Monitor OFF는 화면 잠자기이며 화면 잠금은 아닙니다. 키보드/마우스로 다시 켤 수 있습니다.
앱은 AI Agent를 대신 실행하거나 재시작하지 않습니다. 시스템 잠자기를 제어합니다.

삭제: 메뉴의 설정 > 보조 서비스 제거 > 종료 > 앱을 휴지통으로 이동.
드물게 강제 종료 후 잠자기 설정이 남으면 앱을 다시 열고 OFF로 복구하세요.
보조 서비스까지 제거된 경우 터미널에서 다음 명령으로 복구할 수 있습니다:
sudo /usr/bin/pmset -a disablesleep 0
