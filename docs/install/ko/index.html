Mac에 pika 설치하기: PKG와 보조 서비스

응용 프로그램에 설치하고, 메뉴 막대에서 사용하세요.

  1. 01
    pikaSession OFFQuit · 종료

    기존 pika 종료

    Session을 OFF로 바꾼 뒤 메뉴 막대의 pika → 종료를 선택하세요. 창의 ×를 누르면 앱은 계속 실행 중입니다.

  2. 02
    PKG→
    pikaApp + Helper

    PKG 설치

    다운로드한 pika PKG를 열고 macOS 설치 프로그램에서 계속 진행해 관리자 승인을 완료하세요. 앱과 보조 서비스가 함께 설치됩니다.

  3. 03
    pika→
    ● ● ●pikaSession Monitor

    pika 실행

    응용 프로그램에서 pika를 여세요. 제어창이 전면에 나타납니다. 보조 서비스 연결을 확인하고 Session ON → 덮개 닫기 순서로 사용하세요.

PKG나 pika 실행 시 개발자를 확인하거나 앱을 검증할 수 없다는 경고가 나오면, 출처를 신뢰할 때만 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택하세요. 현재 빌드는 Developer ID 서명·공증이 없습니다.

“컴퓨터를 손상시킵니다” 또는 “앱이 손상되었습니다”라는 경고는 다릅니다. 이 경우 진행하지 말고 다운로드를 확인하세요.

Apple 공식 앱 실행 안내 ↗

앱은 열렸는데 Session이 시작되지 않나요?

앱 실행 허용과 보조 서비스 설치는 별개입니다. “그래도 열기”만으로 보조 서비스 연결 문제가 해결되는 것은 아닙니다.

  1. 홈페이지에서 최신 pika 통합 PKG를 받으세요.
  2. Session을 OFF로 바꾸고 메뉴 막대에서 pika를 종료한 뒤 PKG를 실행하세요.
  3. 설치 완료 후 pika를 다시 여세요. 다시 실패하면 설치 프로그램 → 윈도우 → 설치 프로그램 로그에서 이유를 확인할 수 있습니다.

보조 서비스는 관리자 권한이 필요한 전원 제어를 담당합니다. 설치 내용을 확인한 뒤 승인하세요. 설치 파일도 macOS에 차단되면 출처를 신뢰할 때만 같은 “그래도 열기” 절차를 사용하세요.

준비되면: Session ON → 맥북 덮개 닫기.
