pika 설치하기

응용 프로그램에 설치하고, 메뉴 막대에서 사용하세요.

  1. 01
    pika→
    Applications

    응용 프로그램으로 드래그

    다운로드한 DMG를 열고 pika를 Applications로 드래그하세요. 대치 설치라면 기존 앱을 먼저 종료하세요.

  2. 02
    pika→
    ● ● ●pikaSession Monitor

    pika 열기

    응용 프로그램 폴더에서 pika를 여세요. 실행하면 제어창이 나타나고, 창을 닫아도 메뉴 막대에서 계속 사용할 수 있습니다.

  3. 03
    ⚙ 개인정보 보호 및 보안
    pika그래도 열기

    macOS가 실행을 차단할 때만

    개발자를 확인할 수 없거나 앱을 검증할 수 없다는 경고라면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택하세요. 출처를 신뢰할 때만 다시 열기를 승인하세요.

현재 빌드는 Developer ID 서명·공증이 없어 pika의 안내창이 뜨기 전에 macOS가 실행을 막을 수 있습니다. 그때는 이 웹 안내를 이용하세요.

“컴퓨터를 손상시킵니다” 또는 “앱이 손상되었습니다”라는 경고는 다릅니다. 이 경우 진행하지 말고 다운로드를 확인하세요.

Apple 공식 앱 실행 안내 ↗

앱은 열렸는데 Session이 시작되지 않나요?

앱 실행 허용과 보조 서비스 설치는 별개입니다. “그래도 열기”만으로 보조 서비스 연결 문제가 해결되는 것은 아닙니다.

  1. pika의 설치 안내에서 보조 서비스 설치를 선택하세요.
  2. 보조 서비스 설치 파일을 다운로드하고, pika를 종료한 뒤 설치 파일을 여세요.
  3. macOS 설치 프로그램에서 관리자 승인을 거쳐 완료한 다음 pika를 다시 실행하세요.

보조 서비스는 관리자 권한이 필요한 전원 제어를 담당합니다. 설치 내용을 확인한 뒤 승인하세요. 설치 파일도 macOS에 차단되면 출처를 신뢰할 때만 같은 “그래도 열기” 절차를 사용하세요.

준비되면: Session ON → 맥북 덮개 닫기.
