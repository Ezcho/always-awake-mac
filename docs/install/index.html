Install pika

A home in Applications. Controls in your menu bar.

  1. 01
    pika→
    Applications

    Drag to Applications

    Open the downloaded DMG. Drag pika onto Applications. If replacing a version, quit the old app first.

  2. 02
    pika→
    ● ● ●pikaSession Monitor

    Open pika

    Open pika from Applications. Its controls appear in a window at launch; closing that window keeps pika in the menu bar.

  3. 03
    ⚙ Privacy & Security
    pikaOpen Anyway

    If macOS blocks opening

    For an unidentified-developer or unverified-app warning, use System Settings → Privacy & Security → Open Anyway. Confirm Open only if you trust this download.

The current build is not Developer ID signed or notarized. macOS may stop it before pika can show its own guide. The steps here remain available in your browser.

If macOS says the app will damage your computer or is damaged, stop and check the download; this is a different warning.

App opened, but Session will not start?

Opening the app and installing its helper are separate steps. “Open Anyway” alone does not repair a helper connection.

  1. In pika’s setup guide, choose Install helper service.
  2. Download the helper installer, then quit pika before opening it.
  3. Complete the macOS Installer with your administrator approval, then reopen pika.

The helper enables privileged power controls. Review the installer before approving. If macOS blocks that installer, follow the same app-specific Open Anyway flow only if you trust it.

When ready: Session ON → close your MacBook’s lid.
