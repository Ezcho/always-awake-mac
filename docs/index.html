macOS용 다운로드

1.0.3 MVP · macOS 13+ · Apple Silicon / Intel

  1. DMG에서 앱을 Applications로 옮기세요.
  2. 앱 실행 후 제어창에서 권한 허용…
  3. Session ON, 화면만 끄려면 Monitor OFF.

창의 X를 누르면 메뉴 막대에서 계속 실행됩니다.
Option+클릭으로 Session을 바로 전환할 수 있습니다.
과열·방전 보호는 백그라운드에서 동작합니다.

MVP 설치 및 안전 안내

Apple 서명·공증 전 테스트 빌드입니다. 실행이 차단되면 출처 확인 후 macOS 개인정보 보호 및 보안에서 앱 실행을 허용해야 합니다. 최초 보조 서비스 승인과 실기기 덮개 닫힘 검증이 필요합니다.

외장 화면 없이 덮개를 닫으면 배터리 25%·높은 열 상태, 일반 사용은 15%·위험한 열 상태에서 세션을 끄고 잠자기로 전환합니다. 전원과 외장 화면을 연결한 Desktop 상태에서는 위험한 열 상태가 기준입니다. 배터리 기준은 외부 전원이 없을 때 적용합니다. 가방 안 사용의 안전을 보장하지 않습니다.

삭제하려면 메뉴의 설정 → 보조 서비스 제거 후 종료하세요. 업데이트도 기존 세션과 보조 서비스를 먼저 해제하세요.
