MACBOOK GUIDE

# 맥북 덮어도 안꺼지게 하는법

화면은 닫고, 하던 작업은 계속. 외장 모니터를 쓰는 경우와 백그라운드 작업만 필요한 경우를 나눠 알아봅니다.

no-sleep-pika · 2026년 10월 1일

작업만 유지하려면**pika 실행 → Session ON → Monitor OFF → 덮개 닫기**

덮개가 열려 있을 때 Session이나 Monitor를 바꿔도 화면을 즉시 끄지 않습니다.

## 덮으면 꺼지는 걸까요, 잠드는 걸까요?

일반적으로 맥북 덮개를 닫으면 전원이 완전히 꺼지는 대신 잠자기 상태로 들어갑니다. 다시 열었을 때 앱이 그대로 보여도 그동안 빌드나 다운로드, AI 에이전트 작업이 계속 진행됐다는 뜻은 아닙니다. [Apple의 잠자기 안내](https://support.apple.com/ko-kr/guide/mac-help/mh10330/mac)도 덮개 닫기를 잠자기 방법으로 설명합니다.

따라서 “맥북 덮어도 안 꺼지게” 하려면, 화면이 꺼지는 것과 시스템이 잠드는 것을 구분해야 합니다. 화면을 켜 둘 필요 없이 작업만 유지할 수도 있습니다.

## 외장 모니터를 쓰나요?

### 외장 모니터로 계속 작업

외장 화면·키보드·마우스를 연결해 덮고 쓰는 클램쉘 구성을 먼저 확인하세요. 이 용도라면 별도 절전 방지 앱이 필요하지 않을 수 있습니다.

### 화면 없이 작업만 계속

다운로드, 코드 빌드, AI 에이전트를 돌려 두려면 아래 pika 사용 순서를 따라가세요. 먼저 짧은 작업으로 자신의 Mac에서 동작을 확인하면 됩니다.

클램쉘 사용 전에는 덮개를 연 상태에서 외장 화면과 입력 장치가 정상 작동하는지 확인하세요. Apple Silicon Mac에서 액세서리 연결 승인을 요청하면 먼저 승인해야 합니다. [Apple의 덮개를 닫은 상태에서 액세서리 사용 안내](https://support.apple.com/ko-kr/102282)에서 자세히 볼 수 있습니다. 전원과 지원 디스플레이 구성은 해당 Mac 모델의 안내를 함께 확인하세요.

## 외장 모니터 없이 pika로 작업 유지하기

- **pika를 설치하고 실행합니다.** 홈페이지의 통합 PKG로 설치한 뒤 응용 프로그램 폴더의 pika를 여세요. 보조 서비스가 연결되어 있어야 합니다. 설치가 막히면 [설치 도움말](https://no-sleep-pika.online/install/ko/)을 확인하세요.

- **하던 작업을 시작하고 Session을 ON으로 바꿉니다.** 덮개가 열린 상태에서는 화면을 즉시 끄거나 잠그지 않습니다.

- **화면이 필요 없다면 Monitor를 OFF로 둡니다.** Monitor는 Session이 켜져 있을 때 선택할 수 있고, 화면 동작은 덮개를 닫은 뒤 적용됩니다.

- **맥북 덮개를 닫습니다.** Session ON 상태에서 덮개를 닫으면 닫힌 덮개에 맞는 동작을 적용합니다. 통풍되는 책상 위에서 사용하세요.

- **작업이 끝나면 Session을 OFF로 바꿉니다.** pika가 관리하던 잠자기 설정을 복구합니다. Monitor 표시도 OFF가 되지만 화면을 즉시 끄지는 않습니다.

제어창의 × 버튼은 창만 닫습니다. pika를 계속 사용하려면 메뉴 막대에서 실행 중인 상태로 두세요. 아이콘이 다른 항목에 가렸다면 응용 프로그램에서 pika를 다시 열어 제어창을 볼 수 있습니다.

## 진짜 계속 실행되는지 확인하는 방법

처음에는 완료까지 시간이 걸리며 진행 상황을 확인할 수 있는 작업으로 시험하세요. 예를 들어 작업 로그에 시간이 기록되는 빌드나 AI 에이전트 작업이 좋습니다.

- 덮기 직전의 진행률이나 마지막 로그 시간을 확인합니다.

- Session ON 상태에서 덮개를 닫고 잠시 기다립니다.

- 다시 열어 덮여 있던 시간에도 작업 로그나 진행률이 변했는지 확인합니다.

잠금 화면이 나타났다는 이유만으로 실패한 것은 아닙니다. **화면 잠금과 시스템 잠자기는 다릅니다.** 판단 기준은 실제 작업의 진행 기록입니다. 다만 개별 앱이 입력이나 로그인을 기다리고 있으면 pika가 대신 진행해 주지는 않습니다.

## 배터리·발열·네트워크도 확인하세요

pika는 배터리와 macOS의 열 상태를 확인해 보호 기준에 도달하면 세션을 중단할 수 있습니다. 외장 화면 없이 덮개를 닫은 상태에서는 더 보수적인 기준을 사용합니다. 이 기능이 밀폐된 가방 안에서의 사용을 안전하게 만들어 주는 것은 아닙니다.

잠자기를 막는 기능은 Wi-Fi나 VPN, 원격 API 연결을 보장하지 않습니다. 연결이 끊기거나 서비스 사용량 제한에 걸리면 AI 작업은 멈출 수 있습니다. 긴 작업에는 해당 도구의 재시도와 중간 저장 기능도 활용하세요.

현재 배포 파일은 Developer ID 서명·공증이 없어 macOS가 설치를 차단할 수 있습니다. 이 경우 [보안 경고와 설치 안내](https://no-sleep-pika.online/install/ko/)를 확인하세요. macOS 버전이나 장비별 동작은 실제 사용 환경에서 확인해야 합니다.

## 자주 묻는 질문

### Session만 켜고 Monitor는 꺼도 되나요?

네. 화면 없이 작업을 유지하려는 경우의 설정입니다. Session은 작업 유지, Monitor는 덮개를 닫은 뒤의 화면 동작을 담당합니다.

### 덮개를 열면 화면이 바로 꺼지나요?

pika는 덮개를 다시 열면 예약된 화면 끄기를 취소합니다. macOS 자체의 잠금·화면 설정은 별도로 적용됩니다.

### AI 에이전트가 Session을 제어할 수 있나요?

같은 Mac에서 로컬 MCP 클라이언트를 연결하면 상태 확인과 Session·Monitor 제어가 가능합니다. [MCP 연결 절차와 명령어](https://no-sleep-pika.online/guide/ko/#mcp)를 참고하세요.

연결 끊김이나 메뉴 막대 문제는 [pika 전체 사용 가이드](https://no-sleep-pika.online/guide/ko/)에서 이어서 확인할 수 있습니다.

## 맥을 덮어도 작업을 유지하세요

pika는 Session과 Monitor 두 스위치로 제어하는 macOS 메뉴 막대 앱입니다. macOS 13 이상, Apple Silicon·Intel용입니다.
