MacBookを閉じても作業を続ける方法

画面を閉じても、作業は続けたい。外部ディスプレイで操作する場合と、バックグラウンド処理だけを続ける場合を分けて説明します。

no-sleep-pika · 2026-10-01

バックグラウンド処理だけを続けるpikaを開く → Session ON → Monitor OFF → 蓋を閉じる

蓋が開いている間は、SessionやMonitorを切り替えても画面をすぐに消したりロックしたりしません。

蓋を閉じると電源が切れる？外部ディスプレイを使う場合pikaでバックグラウンド処理を続ける処理が続いているか確認するバッテリー・発熱・ネットワーク

蓋を閉じると電源が切れる？

通常、MacBookの蓋を閉じるとシャットダウンではなくスリープに入ります。開き直してアプリが残っていても、ダウンロードやビルド、AI処理がその間ずっと動いていたとは限りません。画面の消灯、画面ロック、システムのスリープは別の状態です。

外部ディスプレイを使う場合

外部画面で作業するなら、まずMacが対応するクラムシェル構成を確認し、ディスプレイ・キーボード・マウスを接続してください。この用途には追加のスリープ防止アプリが不要な場合があります。Apple Silicon Macでアクセサリ接続の許可を求められたら、蓋を閉じる前に許可します。電源や画面構成の条件は機種ごとの案内を確認してください。

pikaでバックグラウンド処理を続ける

  1. ホームページから統合PKGをインストールし、「アプリケーション」のpikaを開いて補助サービスの接続を確認します。
  2. 続けたい作業を開始し、SessionをONにします。
  3. 画面が不要ならMonitorをOFFにします。MonitorはSessionがONの間だけ選択できます。
  4. 蓋を閉じると、その状態に合わせた画面設定が適用されます。通気のよい机の上で使用してください。
  5. 終わったらSessionをOFFにし、pikaが管理したスリープ設定を戻します。Monitorの表示もOFFになりますが、画面は直ちに消えません。

処理が続いているか確認する

まず短い作業で試しましょう。進捗やログの時刻を記録してから蓋を閉じ、開き直してその間に処理が進んだか確認します。ロック画面だけでは処理停止と判断できません。アプリが入力やログインを待っている場合はpikaが代行することはできません。×は操作ウィンドウを閉じるだけです。メニューバーのアイコンが隠れた場合は「アプリケーション」からpikaを開き直せます。

バッテリー・発熱・ネットワーク

バッテリー残量やmacOSの熱状態が保護基準に達すると、pikaはセッションを終了することがあります。蓋を閉じて外部画面がない場合は基準が厳しくなりますが、密閉したバッグ内で安全に動かせるという意味ではありません。Wi-Fi、VPN、外部APIの接続は保証されないため、長い作業にはツール側の再試行や途中保存も利用してください。現在の配布ファイルはDeveloper ID署名・公証がなく、macOSがインストールをブロックする場合があります。実際の環境で確認してください。
