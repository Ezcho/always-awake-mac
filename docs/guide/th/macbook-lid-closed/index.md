# วิธีให้ MacBook ทำงานต่อแม้พับฝาเครื่อง

พับหน้าจอแล้วให้งานทำต่อ เลือกวิธีให้เหมาะกับการใช้จอภายนอกหรือการรันงานเบื้องหลังเท่านั้น

no-sleep-pika · 2026-10-01

สำหรับงานเบื้องหลัง**เปิด pika → Session ON → Monitor OFF → พับฝาเครื่อง**

การเปลี่ยน Session หรือ Monitor ขณะเปิดฝาอยู่จะไม่ดับหรือล็อกหน้าจอทันที

## พับฝาแล้วพักเครื่องหรือปิดเครื่อง?

ปกติการพับ MacBook จะทำให้เข้าสู่โหมดพักเครื่อง ไม่ใช่ปิดเครื่องทั้งหมด การเปิดมาแล้วยังเห็นแอปอยู่ไม่ได้แปลว่าการดาวน์โหลด บิลด์ หรือ AI ทำงานต่อเนื่องตลอดเวลา หน้าจอดับ หน้าจอล็อก และระบบพักเครื่องเป็นคนละสถานะ

[คำแนะนำอย่างเป็นทางการจาก Apple](https://support.apple.com/en-gb/guide/mac-help/mh10330/mac)

## ใช้จอภายนอกอยู่หรือไม่?

ถ้าจะทำงานบนจอภายนอก ให้ตรวจสอบการใช้งานแบบพับฝาที่ Mac รุ่นนั้นรองรับ แล้วต่อจอ คีย์บอร์ด และเมาส์ อาจไม่จำเป็นต้องใช้แอปป้องกันการพักเครื่องเพิ่ม หาก Mac ที่ใช้ Apple Silicon ขออนุญาตเชื่อมต่ออุปกรณ์เสริม ให้ยอมรับก่อนพับฝา ตรวจสอบเงื่อนไขด้านไฟเลี้ยงและจอของรุ่นที่ใช้ด้วย

[คำแนะนำอย่างเป็นทางการจาก Apple](https://support.apple.com/en-us/102282)

## ให้งานทำต่อด้วย pika

- ติดตั้ง PKG แบบครบชุดจากหน้าแรก เปิด pika ใน Applications และตรวจสอบว่าบริการเสริมเชื่อมต่อแล้ว

- เริ่มงานที่ต้องการ แล้วเปิด Session ON

- ตั้ง Monitor OFF หากไม่ต้องการหน้าจอ โดยเลือก Monitor ได้เมื่อ Session เปิดอยู่เท่านั้น

- พับฝาเครื่องเพื่อใช้การตั้งค่าหน้าจอสำหรับสถานะนั้น วางบนโต๊ะที่ระบายอากาศได้ดี

- เมื่อเสร็จแล้วปิด Session เพื่อคืนการตั้งค่าพักเครื่องที่ pika จัดการ Monitor จะแสดง OFF ด้วย แต่ไม่ดับหน้าจอทันที

## ตรวจสอบว่างานยังเดินต่อ

ทดลองสั้น ๆ ก่อน โดยจดความคืบหน้าหรือเวลาในบันทึก พับฝาขณะ Session ON แล้วเปิดดูว่ามีความคืบหน้าในช่วงนั้นหรือไม่ การเห็นหน้าจอล็อกไม่ได้ยืนยันว่างานหยุด หากแอปรอข้อมูลหรือการเข้าสู่ระบบ pika ไม่สามารถทำแทนได้ ปุ่ม × ปิดเฉพาะหน้าต่างควบคุม ถ้าไอคอนแถบเมนูถูกบัง ให้เปิด pika จาก Applications อีกครั้ง

## ข้อจำกัดด้านแบตเตอรี่ ความร้อน และเครือข่าย

pika อาจจบเซสชันเมื่อแบตเตอรี่หรือสถานะความร้อนของ macOS ถึงเกณฑ์ป้องกัน เกณฑ์จะเข้มงวดขึ้นเมื่อพับฝาโดยไม่มีจอภายนอก แต่ไม่ได้ทำให้การรันในกระเป๋าปิดปลอดภัย การป้องกันพักเครื่องไม่รับประกัน Wi-Fi, VPN หรือ API ให้ใช้การลองใหม่และบันทึกความคืบหน้าสำหรับงานยาว ไฟล์ปัจจุบันยังไม่มีลายเซ็น Developer ID หรือการรับรองจาก Apple จึงอาจถูก macOS บล็อกการติดตั้ง ควรตรวจสอบกับเครื่องและระบบของคุณ
