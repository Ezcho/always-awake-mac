# Cara agar MacBook tetap bekerja saat layar ditutup

Tutup layar, lanjutkan pekerjaan. Pilih cara untuk bekerja dengan monitor eksternal atau hanya menjalankan tugas di latar belakang.

no-sleep-pika · 2026-10-01

Untuk tugas latar belakang**Buka pika → Session ON → Monitor OFF → tutup layar**

Mengubah Session atau Monitor saat layar terbuka tidak langsung mematikan atau mengunci layar.

## Tidur atau mati saat ditutup?

Menutup MacBook biasanya membuatnya tidur, bukan mematikannya sepenuhnya. Aplikasi yang masih terbuka setelahnya tidak membuktikan unduhan, build, atau tugas AI terus berjalan. Layar mati, layar terkunci, dan sistem tidur adalah keadaan yang berbeda.

[Petunjuk resmi Apple](https://support.apple.com/en-gb/guide/mac-help/mh10330/mac)

## Memakai monitor eksternal?

Untuk bekerja di layar eksternal, periksa konfigurasi clamshell yang didukung Mac, lalu hubungkan monitor, keyboard, dan mouse. Cara ini mungkin tidak memerlukan aplikasi pencegah tidur tambahan. Jika Mac Apple Silicon meminta izin aksesori, berikan sebelum menutup layar. Periksa persyaratan daya dan monitor untuk model Anda.

[Petunjuk resmi Apple](https://support.apple.com/en-us/102282)

## Menjalankan tugas dengan pika

- Pasang PKG lengkap dari beranda, buka pika di Applications, lalu pastikan layanan pembantu terhubung.

- Mulai tugas dan ubah Session menjadi ON.

- Biarkan Monitor OFF jika tidak memerlukan layar. Monitor hanya dapat dipilih saat Session ON.

- Tutup layar untuk menerapkan pengaturan layar dalam keadaan tertutup. Gunakan di meja dengan ventilasi baik.

- Setelah selesai, ubah Session menjadi OFF untuk memulihkan pengaturan tidur yang dikelola pika. Monitor juga tampil OFF tanpa langsung mematikan layar.

## Pastikan pekerjaan tetap berjalan

Lakukan uji singkat: catat kemajuan atau waktu log, tutup layar dengan Session ON, lalu buka lagi dan periksa kemajuan selama interval tersebut. Layar terkunci bukan bukti tugas berhenti. pika tidak dapat menggantikan masukan atau login yang ditunggu aplikasi. Tombol × hanya menutup jendela kontrol. Jika ikon bar menu tersembunyi, buka pika dari Applications.

## Batas baterai, suhu, dan jaringan

pika dapat mengakhiri sesi ketika baterai atau kondisi termal macOS mencapai batas perlindungan. Batas lebih ketat saat layar ditutup tanpa monitor eksternal, tetapi ini tidak membuat penggunaan dalam tas tertutup aman. Pencegahan tidur tidak menjamin Wi-Fi, VPN, atau API tetap terhubung; gunakan fitur percobaan ulang dan checkpoint untuk tugas panjang. Unduhan saat ini belum ditandatangani Developer ID atau dinotarisasi, sehingga macOS dapat memblokir instalasi. Uji pada perangkat dan sistem Anda.
